# 題庫資料檔

## situations.json — 情境題庫

生活常識與安全教育題，出題時從中隨機抽出、選項順序打亂。

每一題的欄位：

| 欄位 | 說明 |
|---|---|
| `id` | 唯一編號，格式 `分類-流水號`（例 `traffic-01`） |
| `category` | 分類代碼：`traffic` 交通安全、`danger` 危險辨識、`routine` 生活常規、`manners` 禮貌與社交、`hygiene` 衛生習慣 |
| `question` | 題目文字（也用於語音朗讀） |
| `image` | 情境圖（emoji 場景組合） |
| `options[]` | 2~4 個選項：`text` 選項文字、`emoji` 選項圖示、`correct: true` 標在正確答案上（每題恰好一個） |
| `explanation` | 答錯時的語音解釋（為什麼要這樣做） |

### 家長加題方式

直接在 `questions` 陣列裡照同樣格式加一筆即可。注意：

- `id` 不能重複。
- 恰好一個選項標 `"correct": true`。
- 錯誤選項要設計成「明顯不對」的行為，避免模稜兩可。
- `explanation` 用小孩聽得懂的話解釋原因，會由語音唸出。

## vocab.json — 認知／英文題詞彙庫

題目產生器用的素材，依類別分組（動物、水果、食物、交通工具、身體部位、顏色、形狀）。

| 欄位 | 說明 |
|---|---|
| `zh` | 中文名稱（認知題題目與選項） |
| `en` | 英文名稱（英文單字題與英文語音） |
| `emoji` | 對應圖像（數數題會重複排列此 emoji） |
| `hex` | 僅顏色：色塊顏色 |
| `svg` | 僅形狀：對應的內建 SVG 圖形代碼 |
| `hard` | 標 `true` 的詞（含顏色與形狀）只在「挑戰」以上難度出現 |

各題型取用方式：

- **認知（動物等）**：「哪一個是長頸鹿？」→ 從同類別抽 1 正解 + 2~3 干擾項，顯示 emoji 選項。
- **認知（顏色）**：「哪一個是紅色的？」→ 用 `hex` 畫色塊當選項。
- **找不同類**：「哪一個不是動物？」→ 取 N-1 個同類 + 1 個異類；干擾類別經過挑選避免語意重疊（水果也是食物，所以兩者不互為干擾）。
- **認知（形狀）**：「哪一個是三角形？」→ 用 `svg` 畫圖形當選項（顏色隨機）。
- **數數**：「圖裡有幾隻貓？」→ 隨機挑一種 emoji 重複 N 次排列，數字選項。
- **加減**：「3 + 2 = ?」→ 用同一種 emoji 分兩組呈現。
- **英文單字**：「Which one is an apple?」→ 用 `en` 出題並以英文語音朗讀，emoji 選項。
